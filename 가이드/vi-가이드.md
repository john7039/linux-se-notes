# vi / vim 가이드

> 서버에 기본으로 깔린 유일한 편집기. **SE에게 선택이 아니라 필수.**
> 설정 파일을 고치려면 반드시 거쳐야 한다.

---

# 1. 모드 — 이것부터 이해해야 한다

vi는 다른 편집기와 근본적으로 다르다. **글자를 쳐도 입력되지 않는다.**

```
일반 모드 (Normal)   ← 시작하면 여기. 키보드가 전부 "명령"
입력 모드 (Insert)   ← 여기서만 글자가 써짐
명령줄 모드 (:)      ← 저장·종료·치환 등
```

| 키 | 동작 |
|---|---|
| `i` | 커서 **앞**에서 입력 시작 |
| `a` | 커서 **뒤**에서 입력 시작 (append) |
| `o` | **아래**에 새 줄 만들고 입력 |
| `O` | **위**에 새 줄 만들고 입력 |
| `I` | 줄 **맨 앞**에서 입력 |
| `A` | 줄 **맨 뒤**에서 입력 |
| `Esc` | 일반 모드 복귀 |

**막히면 무조건 `Esc`.** 화면 아래 `-- INSERT --` 표시로 현재 모드를 알 수 있다.

> 실전에서는 `o`, `A`, `I` 가 특히 유용하다. 설정 파일에 줄을 추가하거나 줄 끝에 옵션을 붙일 때.

# 2. 저장 · 종료

| 명령 | 뜻 |
|---|---|
| `:w` | 저장 (write) |
| `:q` | 나가기 (quit) |
| `:wq` 또는 `:x` | 저장하고 나가기 |
| `:q!` | **저장 안 하고 강제 종료** |
| `:w!` | 강제 저장 (읽기 전용 파일에 권한이 있을 때) |
| `ZZ` | 저장하고 나가기 (일반 모드, `:` 없이) |

**`:q!` 가 탈출구다.** 설정 파일을 만지다 이상해지면 이걸로 빠져나오면 **아무 일도 없던 게 된다.**

## `sudo` 없이 열었다가 저장이 안 될 때

```
:w !sudo tee %
```

그다음 `L` 을 눌러 다시 읽는다. (권한 없이 열어놓고 나중에 깨달았을 때)

# 3. 이동

## 기본

| 키 | 동작 |
|---|---|
| `h` `j` `k` `l` | 좌 · 하 · 상 · 우 (방향키도 됨) |
| `w` / `b` | 다음 / 이전 단어 |
| `0` | 줄 맨 앞 |
| `^` | 줄의 첫 글자 (공백 제외) |
| `$` | 줄 맨 뒤 |

## 파일 단위 — 설정 파일에서 자주 쓴다

| 키 | 동작 |
|---|---|
| `gg` | 파일 맨 처음 |
| `G` | 파일 맨 끝 |
| **`숫자G`** | **n번째 줄로 점프** |
| `:숫자` | 위와 동일 (`:65` + Enter) |
| `Ctrl-f` / `Ctrl-b` | 한 화면 앞 / 뒤 |
| `Ctrl-d` / `Ctrl-u` | 반 화면 앞 / 뒤 |
| `%` | 짝이 되는 괄호로 점프 |

> **`숫자G` 가 실무의 핵심이다.**
> `nginx.conf line 47: syntax error` → `vi nginx.conf` → `47G` → 바로 그 줄.

# 4. 검색 · 치환

## 검색

| 키 | 동작 |
|---|---|
| `/단어` + Enter | 아래 방향 검색 |
| `?단어` + Enter | 위 방향 검색 |
| `n` / `N` | 다음 / 이전 결과 |
| `*` | 커서 밑 단어를 아래로 검색 |

```
:set ic      대소문자 무시 (ignorecase)
:set noic    구분
:noh         검색어 하이라이트 끄기
```

## 치환

```
:%s/찾을것/바꿀것/g
```

| 부분 | 뜻 |
|---|---|
| `%` | 파일 전체 (없으면 현재 줄만) |
| `s` | substitute |
| `g` | 그 줄에 여러 개 있어도 전부 |
| `c` | 하나씩 확인하며 (confirm) |

```
:%s/old/new/gc          전체, 확인하며
:10,20s/old/new/g       10~20번 줄만
:%s#/old/path#/new/path#g    경로 치환은 구분자를 # 로 (슬래시 이스케이프 회피)
```

> **경로를 치환할 때 구분자를 `#` 나 `,` 로 바꾸면** `\/` 이스케이프 지옥을 피할 수 있다.

# 5. 편집

| 키 | 동작 |
|---|---|
| `x` | 커서 위치 글자 삭제 — **주석 `#` 뗄 때 제일 많이 씀** |
| `dd` | 줄 삭제 |
| `dw` | 단어 삭제 |
| `D` | 커서부터 줄 끝까지 삭제 |
| `yy` | 줄 복사 (yank) |
| `p` / `P` | 아래에 / 위에 붙여넣기 |
| `u` | **되돌리기 (undo)** |
| `Ctrl-r` | 다시 실행 (redo) |
| `.` | **직전 명령 반복** ← 강력 |
| `J` | 아래 줄을 현재 줄에 붙이기 |
| `r<문자>` | 한 글자만 교체 |
| `cw` | 단어를 지우고 입력 모드 |
| `C` | 줄 끝까지 지우고 입력 모드 |

숫자를 앞에 붙이면 반복된다: `3dd`(3줄 삭제), `5yy`(5줄 복사), `10x`(10글자 삭제)

**`u` 가 생명줄이다.** 여러 번 눌러 계속 거슬러 올라갈 수 있다.

## 여러 줄 주석 처리 (비주얼 블록)

```
Ctrl-v          비주얼 블록 모드
  j j j         범위 선택 (아래로)
  I             블록 맨 앞에서 입력
  #             주석 문자 입력
  Esc           → 선택한 모든 줄에 적용됨
```

주석 해제는 `Ctrl-v` → 범위 선택 → `x`

> 설정 파일에서 여러 줄을 한 번에 주석 처리할 때 쓴다.

# 6. 설정 (`:set`)

| 명령 | 효과 |
|---|---|
| `:set nu` / `:set nonu` | 줄 번호 켜기 / 끄기 |
| `:set list` | 공백·탭을 눈에 보이게 |
| `:set paste` | **붙여넣기 모드** — 자동 들여쓰기 방지 |
| `:set nopaste` | 해제 |
| `:syntax on` | 문법 강조 |
| `:set ic` | 검색 시 대소문자 무시 |

> **`:set nu` 는 설정 파일 다룰 때 필수.** 에러 메시지가 줄 번호로 나오니까.

> **`:set paste` 를 모르면 고생한다.** 들여쓰기된 텍스트를 붙여넣으면 자동 들여쓰기가 겹쳐서 계단처럼 밀린다. 붙여넣기 전에 `:set paste`, 끝나면 `:set nopaste`.

## 영구 설정 `~/.vimrc`

```vim
set number              " 줄 번호
syntax on               " 문법 강조
set hlsearch            " 검색 결과 강조
set incsearch           " 입력하면서 바로 검색
set ignorecase          " 검색 시 대소문자 무시
set smartcase           " 단, 대문자를 쓰면 구분
set tabstop=4
set shiftwidth=4
set expandtab           " 탭을 공백으로
set backspace=indent,eol,start
set laststatus=2        " 상태줄 항상 표시
set showcmd             " 입력 중인 명령 표시
```

> ⚠️ 서버 설정 파일 중 **`Makefile`, `/etc/fstab` 등은 탭이 의미를 가진다.** `expandtab` 이 문제를 일으킬 수 있으니 주의.

# 7. 실무 패턴 — 설정 파일 편집

## 주석 해제 + 값 변경 (가장 흔한 작업)

`#Port 22` → `Port <SSH_PORT>` 로 바꾸기:

```
:set nu           줄 번호 켜기
/Port             검색
0                 줄 맨 앞으로
x                 # 삭제
$                 줄 맨 뒤로
xx                "22" 삭제 (x 두 번)
a                 입력 모드
<SSH_PORT>              입력
Esc
:wq
```

**더 쉬운 방법**: 그 줄에서 `dd` 로 통째로 지우고, `O` 로 위에 새 줄을 만들어 처음부터 타이핑.

**가장 쉬운 방법**: 치환

```
:%s/^#Port 22/Port <SSH_PORT>/
```

## 파일 끝에 줄 추가

```
G                 맨 끝으로
o                 아래에 새 줄 + 입력 모드
(내용 입력)
Esc
:wq
```

## vi 없이 한 줄 추가하기

vi가 번거로우면 셸에서 바로:

```bash
echo 'UUID=... /data xfs defaults 0 0' | sudo tee -a /etc/fstab
```

`tee -a` 는 **이어쓰기**. `sudo` 와 `>>` 를 같이 쓰면 권한 문제가 생기므로 `tee` 를 쓴다.

> ⚠️ **`-a` 를 빼면 파일 전체가 날아간다.** 반드시 확인할 것.

# 8. ⚠️ 자주 겪는 함정

## ① 없는 파일을 열면 빈 파일이 만들어진다

**경로를 잘못 쳐도 에러 없이 그냥 열린다.** 그래서 오타를 눈치채기 어렵다.

> **파일을 열었는데 비어 있으면 → 경로 오타를 의심할 것.**
> `:set nu` 로 줄 번호를 켜보면 내용이 있는지 바로 안다.
> 혹은 열기 전에 `ls -l <경로>` 로 확인.

## ② 지금 어느 기기에 있는가

SSH로 서버에 붙은 터미널에서 `vi ~/파일` 을 열면 **서버의 파일**이 열린다. 맥의 파일이 아니다.

```bash
hostname        # 나는 어디에 있는가
whoami          # 나는 누구인가
pwd             # 지금 위치
```

**명령을 치기 전에 확인하는 습관을 들일 것.**

## ③ 스왑 파일 경고

```
E325: ATTENTION
Found a swap file by the name ".xxx.swp"
[O]pen Read-Only, (E)dit anyway, (R)ecover, (D)elete it, (Q)uit, (A)bort:
```

이전에 vi를 비정상 종료해서 남은 임시 파일이다.

- 저장 안 된 변경사항이 없다면 → **`D`** (Delete it)
- 복구하고 싶다면 → `R` (Recover)

## ④ 붙여넣기가 계단처럼 밀린다

자동 들여쓰기 때문이다. → `:set paste` 후 붙여넣고 `:set nopaste`

## ⑤ 저장이 안 된다 (`E45: 'readonly'`)

`sudo` 없이 열었다. → `:w !sudo tee %` 또는 `:q!` 후 `sudo vi` 로 다시.

# 9. 설정 파일 편집 안전 수칙

```bash
# ① 백업 먼저 — 습관으로
sudo cp /etc/xxx/xxx.conf /etc/xxx/xxx.conf.bak

# ② 편집
sudo vi /etc/xxx/xxx.conf

# ③ 문법 검사 — 반영 전에 반드시
sudo nginx -t          # nginx
sudo sshd -T           # sshd 최종 적용값
sudo mount -a          # fstab
sudo visudo -c         # sudoers

# ④ 반영
sudo systemctl reload <서비스>

# ⑤ 실제 동작 확인
```

> **`sudoers` 파일은 절대 `vi` 로 직접 열지 말 것.** 문법이 틀리면 `sudo` 자체를 못 쓰게 된다.
> 반드시 **`sudo visudo`** 를 쓴다 — 저장할 때 문법을 검사해준다.

# 10. 빠른 참조

```
[모드]
i a o O I A       입력 모드 진입 (앞/뒤/아래줄/위줄/줄앞/줄끝)
Esc               일반 모드

[저장·종료]
:w  :q  :wq  :q!  저장 / 나가기 / 저장후나가기 / 강제종료

[이동]
gg  G  숫자G      맨앞 / 맨끝 / n번째 줄
0  ^  $           줄 맨앞 / 첫글자 / 줄 맨뒤
w  b              다음/이전 단어

[검색·치환]
/단어  n  N       검색 / 다음 / 이전
:%s/A/B/g         전체 치환
:%s/A/B/gc        확인하며 치환

[편집]
x  dd  dw  D      글자/줄/단어/줄끝까지 삭제
yy  p  P          복사 / 아래붙여넣기 / 위붙여넣기
u  Ctrl-r  .      되돌리기 / 다시실행 / 직전명령 반복
Ctrl-v            비주얼 블록 (여러 줄 주석 처리)

[설정]
:set nu           줄 번호
:set paste        붙여넣기 모드
```

## RHCSA 관련

시험은 **실기**이고 GUI가 없다. 설정 파일 편집은 전부 vi로 한다.
외부 자료는 못 쓰지만 **시스템 안의 문서는 쓸 수 있다**:

```bash
man vim
vimtutor          # 대화형 튜토리얼 (약 30분)
```

> `vimtutor` 는 한 번 끝까지 해볼 가치가 있다.
