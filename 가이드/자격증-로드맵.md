## ② RHCSA — 가장 추천

**Red Hat Certified System Administrator (EX200)**

| 항목 | 내용 |
|---|---|
| **왜** | 지금 하고 있는 공부가 **그대로 시험 범위** |
| **형식** | **실기 100%** — 실제 RHEL 시스템에 접속해 문제 해결. 객관식 없음 |
| **가치** | "안다"가 아니라 **"할 줄 안다"** 를 증명하는 거의 유일한 자격 |
| **비용** | 50만원 내외 (변동 있음 — 레드햇 공식 사이트에서 확인 필요) |
| **유효기간** | 3년 |

> 정확한 응시료·시험 시간·합격 기준은 응시 전 **레드햇 공식 사이트에서 직접 확인**할 것. 정책이 바뀐다.

### 시험 범위 = 지금 배우는 커리큘럼

| RHCSA 범위 | 커리큘럼 |
|---|---|
| 사용자·그룹·권한 관리 | 1단계 ✅ |
| LVM, 파일시스템, `/etc/fstab` | 1단계 ✅ |
| 프로세스 · systemd 서비스 관리 | 1단계 ✅ |
| 네트워크 설정 (`nmcli`) | 2단계 ✅ |
| 방화벽 (`firewall-cmd`) | 2단계 ✅ |
| SELinux | 2단계 ✅ |
| 소프트웨어 관리 (`dnf`) | 3단계 |
| 컨테이너 (podman) | 별도 학습 필요 |
| 스크립트 작성 | 4단계 |

**커리큘럼을 끝까지 따라가면 RHCSA 준비가 거의 끝난다.** 별도로 챙길 것은 컨테이너(podman) 정도.

### 왜 SE에게 특히 유효한가

- 국내 SI/SM 업체 다수가 **레드햇 기반 인프라**를 운영한다
- 실기 시험이라 **벼락치기가 안 된다** → 그만큼 신뢰도가 높다
- 실무자들이 인정하는 자격 (정보처리기사와 성격이 다름)

```
정보처리기사  →  "기본기 있음"
RHCSA        →  "실제로 서버를 만질 줄 앎"
```

⚠️ **재응시 비용이 부담이므로 준비를 확실히 하고 응시할 것.**

## ③ 여력이 되면

| 자격 | 성격 | 판단 |
|---|---|---|
| **네트워크관리사 2급** | 국내 (ICQA) | SE 공고에 자주 등장. 저렴하고 부담 적음 |
| **CCNA** | 글로벌 (Cisco) | 네트워크를 제대로 하려면. 비싸고 범위 넓음 |
| **AWS SAA** | 클라우드 | 요즘 SM 업체도 많이 봄. 확장성 좋음 |
| **CKA** | 쿠버네티스 | 컨테이너 운영으로 갈 경우 |
| **리눅스마스터 2급** | 국내 | 저렴하지만 **RHCSA가 있으면 굳이 불필요** |

**SE는 네트워크도 본다.** 리눅스 다음으로 볼 것을 하나 고른다면 네트워크 쪽이 자연스럽다.

## 기억할 것

면접에서 자격증은 **"준비된 사람"이라는 신호** 정도다. 결정적인 것은:

- 실제로 운영해본 서버가 있는가
- 장애를 겪고 해결해본 적이 있는가
- 그 과정을 **문서로 남겼는가**

그래서 졸업프로젝트를 **"운영 프로젝트"** 로 만드는 것이 자격증 한 개 더 따는 것보다 값지다.
